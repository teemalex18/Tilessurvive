# Tiles Survive Team Builder — рабочий контекст

Последнее обновление: 2026-06-12.

Этот файл хранит короткий устойчивый контекст проекта. Перед продолжением
работы после перерыва необходимо сверяться с ним, `BACKLOG.md` и
`PROJECT_DOCUMENTATION.md`.

## Правила совместной работы

- Статус задачи в `BACKLOG.md` меняется только после явного подтверждения
  пользователя.
- Реализованные, но ещё не подтверждённые задачи остаются с `[ ]`.
- Если контекста недостаточно или есть риск его потери, работа
  останавливается и пользователь получает явное сообщение об этом.
- Неподтверждённые игровые правила не выдаются за точные и не включаются в
  расчёты без явной маркировки.
- Перед публикацией выполняются автоматические и браузерные проверки.

## Структура

- `site/` — основное приложение и публикуемый Git-репозиторий.
- `site/index.html` — статическое React-приложение Team Builder.
- `site/BACKLOG.md` — единый список задач.
- `site/PROJECT_DOCUMENTATION.md` — подробная документация проекта.
- `work/` — исследовательские скрипты, дампы, исходные скриншоты и
  промежуточные материалы, не требуемые для работы сайта.

## Подтверждённая модель

- Максимальный уровень героя: `150`; стартовый уровень: `120`.
- Профили героев и инвентарь сохраняются раздельно в `localStorage` только
  после явного нажатия соответствующей кнопки.
- Экипировка не является частью сохранённого профиля героя.
- Сила героя складывается из BattlePower уровня, ранга, навыков и назначенного
  снаряжения.
- Воздухоплаватель может считаться Силачом или Разбойником для получения
  наиболее выгодной фракционной синергии.
- BattlePower навыков подтверждён; полная модель эффектов навыков и
  `skills_base` пока не подтверждена.

## Текущий этап — подтверждён

Цель этапа:

1. Ввести стабильные идентификаторы для 15 экземпляров снаряжения.
2. Ввести два независимых отряда, использующих одни сохранённые профили героев
   и один общий инвентарь.
3. Один предмет может быть назначен только одному герою внутри одного отряда.
4. Один предмет может одновременно присутствовать в отряде №1 и отряде №2,
   поскольку это сравниваемые альтернативные варианты.
5. Добавить сравнение силы двух отрядов.
6. Показывать оба отряда одновременно, один под другим, без вкладок.

Кнопка «Собрать лучший состав» является следующим отдельным блоком после
завершения и подтверждения базовой модели двух отрядов.

## Текущее состояние данных навыков

- Надёжный источник BattlePower навыков: `SurvivorSkillMain.slot9`.
- Источник PVE-эффектов найден: `PveEffect/PveNewEffect.EffectParam2`.
- Универсальное правило выбора масштаба `/10` или `/100` не найдено.
- Старые экстракторы, смешивавшие SLG-параметры описания и PVE-эффекты,
  признаны неверными и не должны использоваться.
